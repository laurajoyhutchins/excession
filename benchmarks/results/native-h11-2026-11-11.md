## Reproduction contract

- Source: pinned h11 Git commit `eefffd80885bddd8dfb42d814de12701ab43ee67`, tree `3a2788d424ec7191625fc7499fb09d84074c75f5`.
- One shared SQLite index, one Rust 1.99.1 release binary, four module seeds (`_connection`, `_headers`, `_events`, `_util`), four role-query kinds (`focus`, `dependencies_direct`, `dependents_direct`, `tests`).
- Five randomized paired repetitions for each of 16 seed/kind combinations, alternating the execution order: 80 pairs, 160 timed native subprocess calls.
- Expected source sets independently read from the complete, Git-authenticated manifest before timing. All **80/80 pairs** agreed. Every compact response carried the matching full-view ID.
- Raw records include pinned Git identities, index/binary/bundle digests, stdout SHA-256 and bytes, wall time, child CPU time, and source path selections.

The native authenticated compact query costs **1.88× median wall time** compared with a direct native graph-only query in this calibration. The extra work authenticates complete view identity and source bindings; it is not an intrinsic graph-traversal speed improvement.

For context, the previous full-view benchmark observed 3,012 median stdout bytes, whereas this separately measured compact-view benchmark observed 298 median bytes. This suggests a large reduction in output amplification but is **not** a controlled same-run comparison of full versus compact output. Reproduce them together before publishing an exact reduction percentage.

## Limits

This is a tiny, fixed h11 calibration, not independent evidence of semantic correctness across languages, improved agent completion, or bounded computational complexity. Both native arms pay process startup and Git/index validation; their execution paths perform different work. Memory and token consumption are not measured, and nearest-rank p95 is descriptive for the observed sample, not a population latency bound.

Run `python3 benchmarks/micro/native_paired.py core/target/release/excession native-calibration.json` after building the pinned release binary. The isolated workflow `native-paired.yml` retains the exact per-query receipt as an artifact.
